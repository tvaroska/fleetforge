## Where we are

`V1` (`R0`–`R6`), `V2` (`R7`–`R11`), `V3`, and the `v0.8.6`/`v0.8.7` security & contract hardening milestones are shipped (`v0.9.2`): Web Serial enrollment, A/B auto-rollback (`ab-4m-v1`), embeddable ESP-IDF/Arduino OTA library, live health & crash-ring telemetry, custom self-test confirmation (`ff_set_selftest`), default-on ECDSA P-256 firmware signing with resumable HTTP `Range` downloads, artifact provenance API, `fleetforge push` CLI + CI workflow templates, multi-project RBAC with scoped `ffa_...` tokens, advisory QEMU simulation gate (`R9`), server-side ESP-IDF container build pipeline (`R10`), multi-ring cohort deploy policy engine (`R11`), and UGV edge-relay gateway hierarchy with airtime-aware scheduling and `ffdelta-v1` binary delta OTA (`V3`).
