## Where we are

`V1` (`R0`–`R6`) and `V2` `R7`–`R8` are shipped: Web Serial enrollment, A/B auto-rollback (`ab-4m-v1`), embeddable ESP-IDF/Arduino OTA library, live health & crash-ring telemetry, custom self-test confirmation (`ff_set_selftest`), ECDSA P-256 firmware signing with resumable HTTP `Range` downloads, artifact provenance API, `fleetforge push` CLI + CI workflow templates, and multi-project RBAC with scoped `ffa_...` tokens. `v0.8.6` (gate and P0 security fixes) is implemented locally (pending `v0.8.6` release). Next up: `v0.8.7` fixes the fifteen P1 findings of the 2026-11-19 review; then complete `V2` (`R9` advisory simulation gate, `R10` server-side container build pipeline, `R11` staged cohort deploy policy), then `V3` robotic swarm hierarchy and delta OTA.
